# Gradual external wiki publish queue

Account: `support@opentibiaservers.com`

## Status
- [x] Source articles generated (509 markdown + MediaWiki)
- [ ] Live on opentibiaservers.com `/wiki/{slug}`
- [ ] GitHub Wiki (repo wiki)
- [ ] Miraheze OT wiki
- [ ] TibiaWiki / Tibia Fandom (only where OT pages are allowed)
- [ ] wiki.gg / OT community wikis if invited

## Do not publish
Wikipedia, Wiktionary, Bulbapedia, Wookieepedia, SCP, TV Tropes, unrelated game wikis.

## Cadence
Publish in batches of 10–25 pages per host after account verify.
